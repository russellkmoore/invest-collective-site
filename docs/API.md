# API Reference

The InvestCollective REST API is available at `/api/v1/`. All requests and responses use JSON.

A machine-readable OpenAPI 3.1 specification is available at `docs/openapi.json` (generated by
`npm run generate:openapi`).

## Authentication

### API Keys

Write operations require an API key. Keys are created and managed in the admin UI at `/admin/api-keys`.

**Usage:** Include the key as a Bearer token in the `Authorization` header:

```
Authorization: Bearer ic_<your-key-here>
```

**Error responses:**

| Status | Meaning |
|---|---|
| `401 Unauthorized` | No `Authorization` header provided |
| `403 Forbidden` | Key is not recognized or has been revoked |

Public read operations (GET theses, GET research) do not require authentication.

### Getting an API Key

1. Log in to the admin panel at `/admin`
2. Navigate to **Settings > API Keys**
3. Click **Create new key** and enter a label
4. Copy the key — it is shown only once

## Endpoints

### Theses

#### `GET /api/v1/theses`

List all investment theses. Public — no auth required.

**Query parameters:**

| Parameter | Type | Description |
|---|---|---|
| `status` | string | Filter by status: `active`, `closed`, `invalidated` |
| `category` | string | Filter by category: `stocks`, `fed_policy`, `sector`, `macro` |

**Response:**
```json
{
  "success": true,
  "data": [
    {
      "id": 1,
      "slug": "sp500-q3-rally",
      "title": "S&P 500 Q3 Rally",
      "hypothesis": "The S&P 500 will reach 5200 by end of Q3...",
      "category": "stocks",
      "status": "active",
      "confidence_score": 0.72,
      "created_at": "2024-01-15T10:00:00Z"
    }
  ]
}
```

**Example:**
```bash
curl https://investcollective.com/api/v1/theses?status=active
```

---

#### `POST /api/v1/theses`

Create a new thesis. Requires API key auth.

**Request body** (see `CreateThesisRequest` schema in `src/lib/validation-schemas.ts`):
```json
{
  "title": "Fed Rate Cut Thesis",
  "hypothesis": "The Fed will cut rates by 50bps before Q4 2024",
  "category": "fed_policy",
  "timeframe": "Q4 2024",
  "source": "human",
  "tags": ["fed", "rates", "macro"],
  "data_points": [
    {
      "name": "Fed Funds Rate",
      "metric_type": "rate",
      "data_source": "fred",
      "data_source_identifier": "FEDFUNDS",
      "target_value": 4.75,
      "target_direction": "below"
    },
    {
      "name": "CPI YoY",
      "metric_type": "percentage",
      "data_source": "fred",
      "data_source_identifier": "CPIAUCSL",
      "target_value": 3.0,
      "target_direction": "below"
    }
  ]
}
```

**Response:** `201 Created`
```json
{
  "success": true,
  "data": { "id": 42, "slug": "fed-rate-cut-thesis" }
}
```

**Example:**
```bash
curl -X POST https://investcollective.com/api/v1/theses \
  -H "Authorization: Bearer ic_<key>" \
  -H "Content-Type: application/json" \
  -d '{"title":"Fed Rate Cut Thesis","hypothesis":"...","category":"fed_policy","timeframe":"Q4 2024","source":"human","data_points":[...]}'
```

---

#### `GET /api/v1/theses/{slug}`

Get a single thesis with its data points and update history. Public.

**Response:**
```json
{
  "success": true,
  "data": {
    "thesis": { "id": 42, "slug": "fed-rate-cut-thesis", "..." },
    "dataPoints": [ { "id": 1, "name": "Fed Funds Rate", "current_value": 5.25, "..." } ],
    "updates": [ { "update_type": "data_update", "content": "...", "created_at": "..." } ]
  }
}
```

**Example:**
```bash
curl https://investcollective.com/api/v1/theses/fed-rate-cut-thesis
```

---

#### `PUT /api/v1/theses/{slug}/data-points`

Update a data point's current value. Requires API key auth.

**Request body** (see `UpdateDataPointRequest` schema):
```json
{
  "data_point_id": 1,
  "value": 5.0,
  "source": "fred"
}
```

**Response:**
```json
{ "success": true, "data": { "confidence_score": 0.65 } }
```

**Example:**
```bash
curl -X PUT https://investcollective.com/api/v1/theses/fed-rate-cut-thesis/data-points \
  -H "Authorization: Bearer ic_<key>" \
  -H "Content-Type: application/json" \
  -d '{"data_point_id":1,"value":5.0,"source":"fred"}'
```

### Research Articles

#### `GET /api/v1/research`

List published research articles. Public — no auth required.

**Query parameters:**

| Parameter | Type | Description |
|---|---|---|
| `topic` | string | Filter by topic string (case-insensitive) |

**Response:**
```json
{
  "success": true,
  "data": [
    {
      "id": 1,
      "slug": "q3-macro-outlook",
      "title": "Q3 2024 Macro Outlook",
      "date": "2024-07-01",
      "topics": "[\"macro\",\"rates\"]",
      "summary": "An analysis of macro conditions heading into Q3...",
      "status": "published"
    }
  ]
}
```

**Example:**
```bash
curl https://investcollective.com/api/v1/research?topic=macro
```

---

#### `POST /api/v1/research`

Create a new research article record. Requires API key auth.

**Request body** (see `CreateArticleRequest` schema):
```json
{
  "title": "Q4 Macro Outlook",
  "date": "2024-10-01",
  "topics": ["macro", "equities"],
  "summary": "Analysis of Q4 market conditions",
  "status": "draft"
}
```

**Response:** `201 Created`
```json
{ "success": true, "data": { "id": 7, "slug": "q4-macro-outlook" } }
```

---

#### `GET /api/v1/research/{slug}`

Get a single article's full content. Public.

### API Keys

#### `POST /api/v1/api-keys`

Create a new API key. Requires API key auth (must already have a key).

**Request body** (see `CreateApiKeyRequest` schema):
```json
{ "label": "My integration key" }
```

**Response:** `201 Created`
```json
{ "success": true, "data": { "id": 3, "key": "ic_...", "label": "My integration key" } }
```

The `key` value is returned **once only** — it cannot be retrieved again.

---

## Response Envelope

All responses follow a consistent envelope:

**Success:**
```json
{ "success": true, "data": <payload> }
```

**Error:**
```json
{ "success": false, "error": "Human-readable message", "details": <optional validation errors> }
```

## Rate Limiting

Rate limiting is enforced at the Cloudflare edge via WAF rules. Limits vary by route:

- Public GET endpoints: 300 req/min per IP
- Authenticated write endpoints: 60 req/min per API key

Clients that exceed limits receive `429 Too Many Requests`.

## Versioning

All endpoints are prefixed with `/api/v1/`. When breaking changes are required, a `/api/v2/` prefix will be
introduced while `/api/v1/` remains available for a deprecation period. Non-breaking additions (new fields,
new optional query params) are made in place without version bumps.
